1️⃣ 📱 iPhone / iPad 正確安裝成桌面 App（避開檔案預覽卡死）

最推薦
為什麼直接點 iPhone「檔案」裡的 .html 不能操作？ Apple iOS 會強制以「Quick Look 靜態預覽」開啟本機 HTML 並停用所有按鈕。請用下方任一方法開啟：
  1. 方法 A（最推薦・支援未來 OTA 線上更新）：點右上角「⬇️ 下載最新版獨立檔」取得 NutriFit_App.html（更名為 index.html），上傳至免費固定網址（例如 GitHub Pages 或登入後的 Netlify 固定站名）。
  2. 用 iPhone Safari 開啟該固定網址 → 點底部中央「分享（方框向上箭頭）」 → 選擇「加入主畫面」，就會變成全螢幕獨立 iOS App！
  3. 方法 B（純離線單機開啟）：於 App Store 安裝免費「HTML Viewer Q」或「Koder」App，從中開啟下載好的 NutriFit_App.html 即可完整互動。

2️⃣ ☁️ 純手機 GitHub Pages + 線上 OTA 無損更新設定（方案 1・免電腦）

  1. 建立免費固定網址（只需做一次）：登入 GitHub 建立一個 Public 倉庫（例如命名 nutrifit，勾選 Add a README file）→ 進入該倉庫 Settings → Pages → Branch 選 main 點 Save，即取得固定網址 https://你的帳號.github.io/nutrifit/。
  2. 建立單一倉庫安全 Token（只需做一次）：前往 GitHub Fine-grained Tokens → Repository access 選 Only select repositories（只勾選 nutrifit） → Permissions 展開 Repository permissions 將 Contents 設為 Read and write → 產生並複製 github_pat_...。
  3. 綁定至本 App 後台：切到「⚙️ 系統與設定」→ 在「🚀 純手機 GitHub 一鍵發佈器」填入帳號、倉庫名 nutrifit 與 Token 點儲存，接著點「📤 推送目前版本至 GitHub」即可把首次版本送上線，再用 Safari 開啟固定網址「加入主畫面」。
  4. 未來純手機 OTA 更新：每次有新版時，在手機複製新版原始碼貼進後台輸入框按「🚀 推送貼上的新版至 GitHub」，等約 20～30 秒後點「🔍 檢查線上新版」→「⚡ 立即無損套用更新」，程式碼即自動升級且 100% 保留所有歷史體重與飲食資料！

3️⃣ 🏃 iOS「捷徑 (Shortcuts)」自動同步 Apple 健康／健身數據

因 iOS 安全政策限制網頁無法直讀 HealthKit，但透過 iPhone 內建免費「捷徑」App 只需設定一次，以後點一下就能把今日步數與活動能量帶入 NutriFit 自動上調運動日營養目標：
  1. 開啟 iPhone「捷徑」App → 右上角「＋」新增捷徑 → 加入動作「尋找健康樣本」（類型選步數，開始日期為今天）與「計算統計資料（總和）」。
  2. 再加入一組「尋找健康樣本」（類型選動態能量，開始日期為今天）與「計算統計資料（總和）」。
  3. 加入動作「打開 URL」，填入你的 NutriFit 固定網址並接上參數：?activeKcal=[動態能量總和]&steps=[步數總和]。
  4. 平日晚上或假日運動完點一下該捷徑，App 就會自動開啟並補償 55% 運動消耗至今日蛋白質、碳水與飲水目標！
